Project

Guitar Coach

🎸 Guitar Coach

A personal AI practice system for learning guitar across three instruments.

Three instrument coaches (electric, acoustic, classical) built on structured curricula — JustinGuitar, Steve Stine theory, and Bradford Werner's classical method. Every session is logged, progress is tracked per instrument, and a two-clock streak system keeps practice consistent. The whole thing lives in one Git repo and auto-deploys this contribution-style heatmap.

  • Three instrument coaches with shared theory spine
  • Two-clock practice streak tracking
  • Instrument-colored contribution heatmap
  • Teacher-lesson overlay + per-year view
  • Markdown practice journal
  • Auto-built & deployed via GitHub Actions

Roadmap

Where this is going

Guitar Coach began as a personal system — the plan is to grow it into a proper product for guitar learners, the way good training tools often start as something built for one person.

Web dashboard

Planned

A full web app over everything the system already tracks — instruments, curricula, and journal in one place, no Git required.

  • Instrument & curriculum browser
  • Session journal & progress
  • Interactive heatmap & stats

Mobile app

Planned

Log a session the moment you finish playing — not when you're back at a laptop. The real key to staying consistent.

  • Quick session capture
  • Offline logging & sync
  • Streak tracking on the go

Wearable nudges

Exploring
